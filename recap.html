흐름

택시 신청부터 갤럭시 검증까지

주황색 항목은 할머니나 제가 직접 문제를 발견한 때입니다.

  1. 앱 이전

    교통약자 택시 신청

    할머니가 장애인(교통약자) 택시를 이용하신다는 걸 알고 알아보니 전남과 광주 모두 지원 대상이었습니다. 두 곳 모두 신청해 드렸습니다.

  2. 앱 이전

    귀가는 광주 센터로

    병원 갈 때 부르는 전남광역이동지원센터는 하루 전 오전 10시에 예약합니다. 진료가 언제 끝날지 몰라 귀가편 시간을 맞출 수 없어서, 집에 올 때는 출발 1시간 전에 부르는 광주광역시교통약자이동지원센터를 쓰기로 했습니다. 두 센터에 직접 전화해 확인했습니다.

  3. 문제

    수첩과 두 개의 번호

    할머니는 단축번호를 외우기 어려워 수첩을 보고 번호를 누르셨고, 이제는 갈 때와 올 때 걸 곳까지 다릅니다.

  4. 10월

    만들고, 빼고, 배포

    버튼 두 개짜리 웹앱을 만들고 화면을 하나씩 뺐습니다. 10월 16일 지금 형태로 GitHub Pages에 배포하고 할머니 폰 홈 화면에 아이콘으로 넣었습니다.

  5. 10월 25일

    할머니: "처음으로 버튼이 어렵다"

    병원에 자주 가시는 시기가 아니어서 주로 가족에게 전화할 때 쓰셨고, 그 화면의 '처음으로' 버튼이 어렵다고 하셨습니다.

  6. 수정

    버튼을 없애고 자동으로 첫 화면

    가족에게 전화를 걸면 첫 화면으로 돌아가게 고쳤습니다.

  7. 발견

    뒤로가기를 여러 번 눌러야 닫힘

    직접 써 보다가 발견했습니다. 두 번 누르면 닫히고, 한 번 누르면 큰 안내가 뜨게 해 달라고 했습니다.

  8. 발견

    아이폰은 되고 갤럭시는 안 됨

    두 기기로 확인하다 발견했습니다. 크롬과 삼성 인터넷 모두에서 15가지 경우를 테스트하라고 기준을 정했습니다.

  9. 확인

    할머니 폰에서 해결 확인

    테스트 30개 통과, 고치기 전 버전에서는 같은 테스트가 실패하는 것까지 확인한 뒤 할머니 폰으로 최종 확인했습니다.

검증 방법

어떻게 확인했나

고치기 전과 지금의 결과 비교는 발표 자료 9번 장면에 있습니다. 여기에는 원인과 확인한 방법을 적었습니다.

원인

안드로이드의 크롬·삼성 인터넷은 사용자가 화면을 누르지 않은 상태에서 페이지가 추가한 뒤로가기 기록을 건너뜁니다. 앱이 켜지자마자 기록을 추가해서, 갤럭시에서만 '뒤로 두 번이면 닫힘'이 안 됐습니다. 그래서 할머니가 화면을 처음 누르는 순간에 기록을 만들도록 바꿨습니다.

방법
  1. 확인할 경우 15가지를 정했습니다 (아래 목록).
  2. 컴퓨터에서 크롬과 삼성 인터넷의 휴대폰 환경을 흉내 내 각각 돌렸습니다. 15가지 × 2 = 30개가 모두 통과했습니다.
  3. 같은 테스트를 고치기 전 버전에도 돌렸습니다. 원인과 관련된 2가지가 실패했고, 건너뛸 기록이 11개 나왔습니다. 테스트가 이 문제를 실제로 잡는다는 뜻입니다.
  4. 마지막으로 할머니 갤럭시에서 직접 확인했습니다.

확인한 15가지

  1. 켜고 화면 누른 뒤 뒤로 1번 → 큰 안내
  2. 이어서 뒤로 1번 더 → 닫힘
  3. 번호 고치기를 저장 3번·취소 1번 한 뒤 뒤로 2번 → 닫힘
  4. 가족 화면에서 뒤로 → 첫 화면
  5. 가족에게 전화한 뒤 자동으로 첫 화면
  6. 번호 추가 화면에서 뒤로 → 첫 화면
  7. 번호 추가 저장 후 뒤로 3번 → 닫힘
  8. 병원 갈 때·집에 올 때가 맞는 센터로 연결
  9. 안내가 3초 뒤 사라짐
  10. 3초 뒤 화면을 누르고 뒤로 → 안내가 다시 뜸
  11. 안내가 떠 있을 때 '병원 갈 때'를 눌러도 연결
  12. 새로고침 후에도 정상
  13. 가족 화면을 5번 들락날락한 뒤 뒤로 2번 → 닫힘
  14. 화면을 한 번도 안 누르고 뒤로 → 안드로이드 규칙대로 닫힘
  15. 갤럭시가 건너뛰는 뒤로가기 기록이 0개
저장 방식 · 설명서

번호는 어디에 저장되나

공개 저장소(코드)누구에게나 공개된 두 센터 번호만 있습니다. 가족 번호는 코드에 없습니다.
할머니 폰가족 번호는 폰 브라우저의 localStorage에 taxi-helper-family-v2라는 이름으로 저장됩니다. 숫자만 저장하고, '-'는 화면에 보여 줄 때만 붙입니다.
서버없습니다. 앱은 GitHub Pages에 올린 웹페이지 하나이고, 번호를 어디로도 보내지 않습니다.
한계폰을 바꾸거나 인터넷 앱의 방문 기록을 지우면 가족 번호도 지워집니다. 그때는 가족이 설명서를 보고 다시 넣어야 합니다.
