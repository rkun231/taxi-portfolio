# 병원 택시 포트폴리오

SK AIGEN 지원용 포트폴리오입니다. 80세가 넘은 외할머니를 위해 만든 웹앱 '병원 택시'를 만든 과정을 담았습니다.

- 발표 자료: https://rkun231.github.io/taxi-portfolio/ (→ 키로 장면 넘기기, ? 키로 조작법)
- 자세히 보기: https://rkun231.github.io/taxi-portfolio/recap.html
- 실제 앱: https://rkun231.github.io/Taxi-helper/?test

페이지 속 체험 휴대폰은 가짜 번호로 동작하며 전화는 걸리지 않습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 발표 자료 (장면 12개, 주소 끝 `#번호`로 바로 열기) |
| `recap.html` | 자세히 보기 (흐름, 체험, 역할, 검증, 질문과 답) |
| `assets/style.css` | 두 페이지 공통 스타일 |
| `assets/phone.js` | 체험 휴대폰 |
| `assets/qr.png` | 발표 자료로 연결되는 QR |

글꼴: Pretendard, Black Han Sans, IBM Plex Mono (모두 SIL Open Font License)
