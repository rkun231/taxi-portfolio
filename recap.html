흐름

택시 신청부터 지금까지

주황색 항목은 할머니나 제가 직접 문제를 발견한 때입니다.

  1. 앱 이전

    교통약자 택시 확인

    할머니가 교통약자 택시를 이용할 수 있는 대상인지 전남 센터에 물어보니, 지원 대상이 맞고 이미 등록돼 있으셨습니다.

  2. 앱 이전

    귀가는 광주 센터로

    전남광역이동지원센터에 귀가편으로도 쓸 수 있는지 물었더니, 하루 전 오전 10시 출발 예약 전화에서 귀가편까지 같이 등록해야 한다고 했습니다. 진료가 언제 끝날지 몰라 귀가 시간을 미리 정할 수 없었습니다. 시간이 바뀌어도 괜찮은지 물어보니, 귀가 시간이 바뀔 것 같으면 이용자 준수 사항 위반이 될 수 있어 안 된다는 답을 들었습니다. 그래서 출발 1시간 전에 부르는 광주광역시교통약자이동지원센터를 추가로 신청해 드렸습니다.

  3. 문제

    수첩과 번호 두 개

    할머니는 단축번호를 외우기 어려워 수첩을 보고 번호를 누르셨고, 이제는 갈 때와 올 때 걸 곳까지 달라졌습니다.

  4. 10월 16일

    바로 만들기 시작

    처음엔 버튼 두 개짜리 웹앱을 만들고 화면을 하나씩 빼서, 지금 모양으로 무료 웹페이지에 올렸습니다.

  5. 10월 25일

    할머니 폰에 설치

    저는 서울, 할머니는 함평에 계셔서 직접 설치해 드릴 수 없었습니다. 카카오톡으로 링크를 보내 카카오톡 안에서 쓰시도록 안내했지만 어려워하셔서, 그나마 가까운 광주에 사시는 외숙모가 할머니 댁에 들르시는 날 홈 화면에 아이콘으로 넣어 주셨습니다.

  6. 10월 25일

    할머니: "처음으로 버튼이 어렵다"

    설치한 날 가족에게 전화해 보시고, 바로 그 화면의 '처음으로' 버튼이 어렵다고 하셨습니다. 어머니와 통화하시며 하신 말씀이라, 통화가 끝난 뒤 어머니께 전해 들었습니다.

  7. 수정

    버튼을 없애고 자동으로 첫 화면

    가족에게 전화를 걸면 첫 화면으로 돌아가게 고쳤습니다.

  8. 발견

    뒤로가기를 10번 넘게 눌러야 닫힘

    직접 써 보니 삼성 인터넷과 크롬 모두에서 문제를 발견했습니다. 원인을 모른 채, 두 번 누르면 닫히고 한 번 누르면 큰 안내가 뜨게 해 달라고 했습니다.

  9. 발견

    아이폰은 되고 갤럭시는 안 됨

    고친 뒤 아이폰과 갤럭시로 각각 눌러 보니 갤럭시에서는 안내가 뜨지 않았습니다. Claude와 원인을 찾아 다시 고쳤습니다.

  10. 확인

    갤럭시에서 해결 확인

    다시 고친 뒤 정말 고쳐졌는지 보려고, 컴퓨터에서 안드로이드 환경을 흉내 내어 크롬과 삼성 인터넷에서 15가지씩 30개 테스트를 돌렸고 모두 통과했습니다. 고치기 전 버전에서는 같은 테스트가 실패하는 것까지 확인한 뒤, 할머니 폰(갤럭시 점프2)과 최대한 비슷한 조건인 어머니 폰(갤럭시 S22)으로 최종 확인했습니다.

  11. 10월 29일

    버튼 사용 기록 시작

    '병원 갈 때'·'집에 올 때' 버튼을 아직 쓰신 적이 없어서, 실제로 쓰시는지 확인하려고 버튼을 누를 때마다 익명으로 기록하기 시작했습니다.

  12. 11월 2일

    홈 화면 아이콘을 큰 글씨로

    아이콘 후보 4개 중 작은 크기에서도 가장 잘 읽히는 노란 바탕 큰 글씨 '병원 택시'를 골라 바꾸고 설명서도 새 아이콘으로 바꿨습니다.

  13. 11월 6일

    사용성 원칙으로 다시 점검

    Claude에게 사용성 점검 기준으로 앱을 점검하게 했고, 나온 것 가운데 할머니 화면에 필요한 것만 직접 골라 고쳤습니다. '전화번호 고치기'를 '가족 번호 고치기'로 바꾸고 가족 전화 버튼과 간격을 넓혔고, 010 번호 자리 수가 틀리면 저장을 막고, 112·119 같은 긴급 번호는 넣을 수 있게 했습니다. 저장하면 '저장했어요'가 뜹니다.

  14. 11월 7일

    AI 검증 제안을 하나씩 골라 반영

    AI가 앱과 이 포트폴리오를 여러 번 검증했고, 나온 제안마다 바꿀지 그대로 둘지 제가 골랐습니다. 설정 화면에 '편집' 버튼을 두어 누를 때만 줄마다 ✕가 나오게 했고, 같은 이름을 두 줄에 쓰면 저장을 막고, 저장·취소 버튼을 화면 아래에 붙였습니다. 설정 화면에서 가족용 설명서도 바로 열 수 있게 했습니다. 고른 내용은 결정 기록 ↗ 에 모두 있습니다.

고치기 전과 지금의 결과 비교는 발표 자료 9번 장면에 있습니다. 여기에는 원인과 확인한 방법을 적었습니다.

처음 상황

처음 앱은 삼성 인터넷과 크롬에서 뒤로가기를 10번 넘게 눌러야 꺼졌습니다. 나중에 알고 보니, 화면을 오갈 때마다 앱이 '뒤로' 단계를 하나씩 쌓아 두고 지우지 않았기 때문이었습니다. 당시에는 원인을 몰라서 뒤로가기를 두 번 누르면 꺼지도록 바꿔 달라고 Claude에게 요청했습니다. 고친 뒤 아이폰에서는 됐지만 갤럭시에서는 안내가 뜨지 않았습니다.

원인

자세히 설명드리자면 갤럭시의 인터넷 앱(크롬·삼성 인터넷)은 사용자가 화면을 누르기 전에 앱이 만든 '뒤로' 단계를 무시합니다. 그래서 갤럭시에서만 안내가 뜨지 않았습니다.

안드로이드의 크롬과 삼성 인터넷은 뒤로가기를 눌러도 못 나가게 막는 사이트를 막으려고, 사용자가 화면을 한 번도 누르지 않은 상태에서 페이지가 만든 뒤로가기 기록을 건너뜁니다. 그런데 앱은 켜지자마자 그 기록을 만들고 있었습니다. 그래서 사용자가 화면을 처음 누르는 순간에 기록을 만들도록 바꿨습니다.

테스트
  1. 처음 고친 뒤 갤럭시에서 안 되는 걸 보고 나서야 '확인은 해 봤어야지' 싶어, 다시 고칠 때는 크롬·삼성 인터넷 모두 15가지 테스트로 확인하라고 했습니다 (아래 목록).
  2. 컴퓨터에서 크롬과 삼성 인터넷의 휴대폰 환경을 흉내 내 각각 돌렸습니다. 15가지 × 2 = 30개가 모두 통과했습니다.
  3. 고치기 전 버전에도 같은 테스트를 돌렸습니다. 원인과 관련된 2가지가 실패했고, 갤럭시가 건너뛰는 숨은 '뒤로' 기록이 11개 나왔습니다. 그래서 테스트가 실제 문제를 잡아낸다는 걸 알았고, 새 버전에서는 그 문제가 사라진 걸 확인했습니다.
  4. 마지막으로 할머니 폰(갤럭시 점프2)과 최대한 비슷한 조건으로, 어머니 갤럭시 S22에서 직접 확인했습니다.

확인한 15가지

  1. 켜고 화면 누른 뒤 뒤로 1번 → 큰 안내
  2. 이어서 뒤로 1번 더 → 닫힘
  3. 번호 고치기를 저장 3번·취소 1번 한 뒤 뒤로 2번 → 닫힘
  4. 가족 화면에서 뒤로 → 첫 화면
  5. 가족에게 전화한 뒤 자동으로 첫 화면
  6. 번호 추가 화면에서 뒤로 → 첫 화면
  7. 번호 추가 저장 후 뒤로 3번 → 닫힘
  8. 병원 갈 때·집에 올 때가 맞는 센터로 연결
  9. 안내가 3초 뒤 사라짐
  10. 3초 뒤 화면을 누르고 뒤로 → 안내가 다시 뜸
  11. 안내가 떠 있을 때 '병원 갈 때'를 눌러도 연결
  12. 새로고침 후에도 정상
  13. 가족 화면을 5번 들락날락한 뒤 뒤로 2번 → 닫힘
  14. 화면을 한 번도 안 누르고 뒤로 → 안드로이드 규칙대로 닫힘
  15. 갤럭시가 건너뛰는 숨은 '뒤로' 기록이 0개
